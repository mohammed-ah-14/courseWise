About CourseWise

A student project at the University of Sharjah, built for the Machine Learning and Web Programming courses.

Why

Registration shouldn't be a guess.

Every term, students pick courses with very little to go on: a friend's opinion, a forum thread, a rumour about one instructor. A single hard course in the wrong term can pull a GPA down for years.

Universities already hold the answer in their grade records. CourseWise turns those records into something a student can use: how a course has graded in the past, how it is likely to grade next term, and what a whole semester adds up to.

Because University of Sharjah grade data is not public, the model is trained on the open grade distributions of the University of Illinois Urbana-Champaign. The pipeline is built so that any university's data could be dropped in.

How it came together

Four stages

  1. 01

    Question

    Can past grades predict how hard a course will be next term, well enough to help a student plan?

  2. 02

    Data

    Two decades of grade distributions, cleaned, merged by section and joined with the course catalogue.

  3. 03

    Model

    History features without leakage, nine model types, time-based validation and one final test on unseen years.

  4. 04

    Website

    A static site in plain HTML, CSS and JavaScript that reads the exported predictions. No frameworks, no server.
